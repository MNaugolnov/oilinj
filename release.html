Перед переходом со старой версии. Изменены сигнатуры двух функций — формулы с ними в старых книгах нужно поправить: PI_Batler_HW_Oilinj получила аргумент re (радиус дренирования) перед rw; OFPHong2 — аргумент Swc: (Sg; Sgc; Swc; Sorg; krog).

Установка

Подключение надстройки

  1. Скачайте oilinj2026.xlam и сохраните в постоянную папку (например, %AppData%\Microsoft\AddIns).
  2. Если файл скачан из интернета: свойства файла › отметьте «Разблокировать».
  3. Excel › Файл › Параметры › Надстройки › Управление: «Надстройки Excel» › Перейти › Обзор › выберите файл.
  4. Убедитесь, что галочка у надстройки стоит, и нажмите ОК. На ленте появится вкладка «Нефтяной инжиниринг v.0.31».
  5. Если вкладки нет — проверьте Центр управления безопасностью › Параметры макросов.
  6. При обновлении со старой версии отключите прежний oilinj.xlam, чтобы функции с одинаковыми именами не конфликтовали.

Проверка после установки

  • В любой ячейке введите =PI_Dupui_Oilinj( и нажмите Ctrl+A — откроется Мастер функций с описанием аргументов.
  • Кнопка «О программе» на ленте должна показывать версию 0.31.
  • Функции также доступны в категории «Определённые пользователем».

Расчётные функции

Модуль Oil_Well_Rates

  • PI_Batler_HW_Oilinj: добавлен аргумент re (радиус дренирования) ПЕРЕД rw: (k, B, mu, Aniz, h, l, re, rw, Skin). Проверка l = 0 до деления.
  • PI_Joshy_HW_Oilinj: анизотропия beta = sqrt(1/Aniz) (Aniz = kv/kh), beta под логарифмом.
  • PI_Li_HW_Frac_no_influx_Oilinj: L_f2 -> Lf_2; Log(h/(2*r_w)).
  • Vogel для ГС: кривая Чена нормирована (f(0)=1, f(1)=0) и согласована по производной — нет разрыва при Pзаб = Pнас.

Модуль Gas

  • Gas_Tkr: Tкр n-бутана 425.12 K; Gas_Tkr/Gas_Pkr: сумма долей сравнивается с 100 с допуском 0.01.
  • my(): температура в °C в формуле вязкости при низком давлении.
  • Q_gas_Dipiu_Oilinj, Q_gas_Joshy_Oilinj: ата -> Па (x98066.5), Pст = 101325 Па, pi точно.
  • Q_gas_Joshy_Oilinj: полуось эллипса дренирования считается по длине ствола l.

Модуль PVT

  • RsKarto: результат в м3/м3 (x0.1781); во 2-й ветке temp вместо Tres.
  • RsClaso: показатели температуры согласованы с PsatClaso (0.172 средняя / 0.13 лёгкая).
  • BoilAl: gamma_oil^-1.20204, Rs^0.74239.
  • Visco1Stan: (1.8*temp - 520).
  • CoilLabedi: множитель 145.041 применяется ко всему выражению.
  • CorNewmancompr_csandst: коэффициент 97.32e-6 (было 97320000).
  • PsatStand_Mod, RsStand_mod: для 0.85<γo<0.9 — оригинальный Standing (раньше 0); Visco1Egbo: для 0.85<γo<0.9 — оригинальная Egbogah-Jack.

Модуль GPNPVT

  • DensWGPN: учитывается растворённый газ (Rsw_scfstb).
  • CoilGPN ниже Pнас: co = -1/Bo·dBo/dp + Bg/Bo·dRs/dp (без лишнего /5.615).
  • ZFactorDranchuk: точность бисекции 1e-7 (была 1e-3).

Модуль OFP

  • OFPLetO: Eoil*Swn^Toil.
  • OFPHong2: добавлен аргумент Swc: (Sg, Sgc, Swc, Sorg, krog).
  • OFPHonog1/OFPHonog2: So = 1 - Sg - Swc.

Модуль Prod_Prediction

  • FQ_Plato: P + (1-P)*exp(-d*t).
  • FW_Frencinst: Qw вместо неопределённой W.

Модуль analysis

  • FA_dF2_a/b/c (модель a*b/c): точные формулы интегрального метода; сумма факторов равна изменению a*b/c.

Модуль Other

  • IFM, IFM2: минимум только среди строк, удовлетворяющих условиям; IFM2 возвращает результат.
  • MVPR: для массивов поиск в SearchColumnNum.

Ошибки компиляции

  • PVT: CorNewmancompr_limest (лишний End Function); ViscoDeGheto, ViscoAl, ViscoBeal, ViscoBergman (недостающие End If). Модуль PVT снова компилируется.
  • Prod_Prediction: Ln() -> Log() в FW_Sazon и FW_arps.
  • Func_description.call_func: убраны вызовы несуществующих процедур; Visco11Kart -> Visco1Kart.

Лента

  • customUI.xml (Office 2007) приведён к актуальной customUI14.xml — нет ссылок на отсутствующие макросы. Подпись вкладки: "Нефтяной инжиниринг v.2026".

Конвертер единиц

  • Пересчёт переписан через коэффициенты к базовой единице СИ. Исправлены: галлон (США), кубический дюйм/ярд/миля, баррель, стокс, мм рт. ст., миля->ярд, дюйм->фут, ккал, кВт·ч, т н.э., фунт->тонна, неделя, °C<->°R/K (273.15), приставки СИ.

Исправление сборки

  • В первой сборке исходный текст модулей PVT, OFP, Prod_Prediction, Func_description, u7_const был упакован так, что Excel читал его не полностью (модули обрезались и не компилировались). Упаковка исправлена; проект проверен в Excel: Debug -> Compile VBAProject проходит без ошибок, функции считаются.

Удалено

  • UserForm1 (старый конвертер) и процедура Form_Load0.
  • Module1 (мёртвый код с ошибкой компиляции).
  • Дублирующая call_func в ЭтаКнига.
  • Описания несуществующих функций УЭЦН/двигателя (Motor*, ESP*) в Func_description.
  • Кнопки/макросы для несуществующих функций: CorNewmancompr_uncsandst, Gas_rokr, UNIFLOW (fail).
