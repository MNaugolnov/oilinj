Установка

Подключение надстройки

  1. Скачайте oilinj.xlam и сохраните в постоянную папку (например, %AppData%\Microsoft\AddIns).
  2. Если файл скачан из интернета: свойства файла › отметьте «Разблокировать».
  3. Excel › Файл › Параметры › Надстройки › Управление: «Надстройки Excel» › Перейти › Обзор › выберите файл.
  4. Убедитесь, что галочка у надстройки стоит, и нажмите ОК. На ленте появится вкладка «Нефтяной инжиниринг v.0.32».
  5. Если вкладки нет — проверьте Центр управления безопасностью › Параметры макросов.
  6. При обновлении отключите прежнюю версию надстройки, чтобы функции с одинаковыми именами не конфликтовали.
При первом открытии Excel компилирует проект надстройки. Если появится ошибка — откройте редактор VBA (Alt+F11) › Debug › Compile VBAProject и сохраните.

Проверка после установки

  • В любой ячейке введите =PI_Dupui_Oilinj( и нажмите Ctrl+A — откроется Мастер функций с описанием аргументов.
  • Кнопка «О программе» на ленте показывает версию 0.32.
  • Функции также доступны в категории «Определённые пользователем».
